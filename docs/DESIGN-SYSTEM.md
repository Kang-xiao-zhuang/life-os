## 视觉原则

- **卡片层级靠 quiet 而非边框**：普通卡有边框+阴影，quiet 卡只有更淡的面；标题也降一级（17px→14px、主文字→次文字）
- **强调靠"去掉卡片"**：首页 MIT 直接坐在背景上，大字 + primary 标签，是首页唯一视觉起点
- **圆角**：card=20px / btn=16px / input=16px / modal=24px（上方圆角）
- **字阶**：24（页标题）/ 17（卡片标题）/ 15（正文）/ 13（次信息）/ 11（标签）
- **间距**：卡片内 18px、quiet 卡内 16px、卡片间 16px、区块间 20px
- **底部导航 5 tab，记录居中凸起**；详情页隐藏底栏
- 深浅色均由 CSS 变量驱动，`html.dark` 切换；灰度不用纯黑

## 迁移自 Kotlin 版的变化

原版是深色优先的冷色系（#12131A + 长春花蓝/薄荷/淡紫 Material 3）。
本版按用户要求统一为 Track100 米白克制风，但保留四功能域的语义色区分（任务橄榄、项目蓝、习惯薄荷、复盘淡紫），以及原版"quiet 卡 + MIT 独占强调"的层次逻辑。
